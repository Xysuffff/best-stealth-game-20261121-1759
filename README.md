## Play

Open `game/index.html` in a browser, or serve locally:

```bash
node serve.ts
# then open http://localhost:8080
```

## Controls

- **WASD / Arrow Keys** - Move
- **Shift** - Sneak (silent, slow)
- **Space / Enter** - Interact
- **Esc** - Pause

## Goal

Infiltrate the museum, avoid guards, steal the artifact, and escape through the main entrance.
